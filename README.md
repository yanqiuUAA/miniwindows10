# miniwindows10


> **一个专为低配置硬件和极致流畅体验而生的 Windows 10 精简镜像。**  
> 移除冗余组件、后台应用及遥测服务，保留核心功能，兼容主流办公与游戏环境。

## 项目介绍
本项目基于 Windows 10 官方原版镜像（22H2）进行离线封装与精简。旨在解决老旧电脑（2GB 内存 / 机械硬盘）运行卡顿的问题，同时移除广告和隐私泄露风险，让你重获纯净、快速的 Windows 体验。

##  特色功能
-  **极致提速**：关闭无用服务与特效，开机内存占用仅 **800MB ~ 1.2GB**。
-  **深度精简**：Cortana、、多余语言包。
-  **隐私保护**：彻底禁用遥测数据收集、广告 ID 及后台应用推送。
-  **兼容性好**：保留 .NET Framework 3.5/4.8、DirectX、打印和蓝牙功能。
-  **游戏优化**：集成游戏模式优化，减少 DPC 延迟。

## 系统要求
- **处理器**：1 GHz 或更快的 x86/x64 处理器（支持 PAE、NX 和 SSE2）
- **内存**：**至少 1.5 GB**（推荐 2 GB 以上）
- **硬盘空间**：**至少 10 GB** 可用空间（推荐 16 GB）
- **显卡**：支持 DirectX 9 或更高版本

## 安装方法
### 方法一：U 盘启动（推荐）
1. 下载 ISO 镜像，使用 **Rufus** 或 **Ventoy** 制作启动 U 盘。
2. BIOS 设置 U 盘为第一启动项，进入安装界面。
3. 选择 **"自定义：仅安装 Windows"**，格式化目标分区（注意备份数据）。

### 方法二：硬盘安装（无需 U 盘）
1. 解压 ISO 镜像至非系统盘根目录（例如 `D:\Win10`）。
2. 运行 `Sources\setup.exe`，根据提示保留或清除文件。
3. 等待约 15-20 分钟完成部署。

##  已知问题 (Known Issues)
- **无法安装累积更新**：因精简了 WinSxS 备份，建议关闭 Windows 更新服务（不影响驱动安装）。
- **WSL 功能不可用**：如需 Linux 子系统，请使用完整版系统。
- **部分日语/韩语字体显示异常**：仅保留简体中文核心字体，需手动补充
